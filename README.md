# Enroll — ระบบรับสมัครนักเรียนออนไลน์

ระบบรับสมัคร/ลงทะเบียนเข้าศึกษาต่อสำหรับโรงเรียน สร้างบน [Now.js](https://nowjs.net) (ฝั่งหน้าเว็บ) และ [Kotchasan](https://www.kotchasan.com/) (PHP ฝั่งเซิร์ฟเวอร์) ผู้สมัครกรอกใบสมัครผ่านเว็บ ตรวจสอบผลการสมัคร และพิมพ์ใบสมัครได้เอง ส่วนเจ้าหน้าที่จัดการผู้สมัคร ประกาศผล และส่งออกข้อมูลได้จากหลังบ้าน

## ความสามารถ

**สำหรับผู้สมัคร**
- กรอกใบสมัครออนไลน์ เลือกระดับชั้นและแผนการเรียน (กำหนดจำนวนตัวเลือกแผนการเรียนได้)
- ที่อยู่แบบเลือกจังหวัด → อำเภอ → ตำบล พร้อมรหัสไปรษณีย์ (ข้อมูลครบทั้งประเทศ)
- แนบไฟล์เอกสาร ตามชนิดไฟล์ที่ผู้ดูแลอนุญาต
- ตรวจสอบผลการสมัคร และพิมพ์ใบสมัครได้
- รองรับภาษาไทยและอังกฤษ

**สำหรับเจ้าหน้าที่**
- ตารางจัดการผู้สมัคร ค้นหา กรอง และดำเนินการกับหลายรายการพร้อมกัน
- ประกาศผล (ผ่าน/ไม่ผ่าน และแผนการเรียนที่ได้รับ) พร้อมสรุปจำนวนผู้สมัคร
- ส่งออกข้อมูลเป็น CSV (เลือกการเข้ารหัสอักขระได้)
- จัดการระดับชั้น แผนการเรียน และหัวข้อผลการเรียน/ข้อมูลผู้ปกครองที่ต้องกรอก
- กำหนดช่วงเวลารับสมัคร รูปแบบเลขที่สมัคร และสิทธิ์การแก้ไขข้อมูล
- ระบบผู้ใช้ สิทธิ์ ภาษา และการตั้งค่าเว็บไซต์ จากแม่แบบ Admin Framework

## ความต้องการของระบบ

- PHP 7.4 ขึ้นไป พร้อมส่วนขยาย `pdo_mysql`, `mbstring`, `zlib`, `json`, `xml`, `openssl`, `gd`, `curl`
- MySQL / MariaDB (ใช้ชุดอักขระ utf8mb4)
- Apache พร้อม `mod_rewrite` และอนุญาต `.htaccess` (`AllowOverride All`)
- ไม่ต้องใช้ Node.js เพื่อรันระบบ ไฟล์ JavaScript ที่คอมไพล์แล้วอยู่ใน `Now/dist/`

## การติดตั้ง

1. ดาวน์โหลดหรือโคลนโปรเจ็ค แล้ววางไว้ใน document root (หรือโฟลเดอร์ย่อย) ของเว็บเซิร์ฟเวอร์

   ```bash
   git clone https://github.com/goragodwiriya/enroll.git
   ```

2. ให้เว็บเซิร์ฟเวอร์เขียนไฟล์ในโฟลเดอร์ `datas/` และ `settings/` ได้ (สร้างให้ถ้ายังไม่มี)

   ```bash
   mkdir -p datas settings
   chmod -R 775 datas settings
   ```

3. เปิดเบราว์เซอร์ไปที่ `http://localhost/enroll/install/` แล้วทำตามขั้นตอน
   ตรวจความพร้อม → ตั้งค่าฐานข้อมูล → ตั้งค่าเว็บไซต์ → สร้างบัญชีผู้ดูแลสูงสุด

4. หลังติดตั้งเสร็จ ให้ลบหรือจำกัดการเข้าถึงโฟลเดอร์ `install/` ตามที่หน้าจอแนะนำ
   แล้วเข้าสู่ระบบด้วยบัญชีผู้ดูแลที่เพิ่งสร้าง

5. ตั้งค่าโรงเรียนที่เมนูของโมดูลรับสมัคร (Enroll) ได้แก่ การตั้งค่าโมดูล (ปีการศึกษา ช่วงเวลารับสมัคร รูปแบบเลขที่สมัคร) ระดับชั้น และแผนการเรียน รวมถึงหัวข้อผลการเรียนและข้อมูลผู้ปกครอง (ต้องมีสิทธิ์ `can_manage_enroll`)

> ฐานข้อมูลที่ติดตั้งใหม่มีระดับชั้นและแผนการเรียนตัวอย่างให้ แก้ไขหรือลบได้ตามต้องการ

### ติดตั้งผ่านบรรทัดคำสั่ง

```bash
# ติดตั้งลงฐานข้อมูลเปล่า (สร้างตาราง ผู้ดูแลสูงสุด และนำเข้าภาษา)
php install/cli-fresh.php <dbname> [prefix] --admin=admin@localhost --password=<รหัสผ่าน>
```

> อย่าใช้รหัสผ่านเริ่มต้น `admin` กับระบบจริง

### อัปเกรดจากรุ่นเก่า

สำรองฐานข้อมูลและโฟลเดอร์ `datas/` ก่อนเสมอ จากนั้นแทนที่ไฟล์ด้วยรุ่นใหม่ (คงโฟลเดอร์ `settings/` และ `datas/` ไว้) แล้วเปิด `http://localhost/enroll/install/` ตัวติดตั้งจะตรวจพบรุ่นเดิมและปรับโครงสร้างฐานข้อมูลให้เอง หรือรันด้วย `php install/cli-upgrade.php`

## โครงสร้างโปรเจ็ค

| โฟลเดอร์ / ไฟล์ | หน้าที่ |
| --- | --- |
| `modules/enroll/` | โมดูลรับสมัครนักเรียน (controllers, models, `admin.js`, ชุดทดสอบ) |
| `modules/index/`, `modules/download/`, `modules/export/`, `modules/timeline/` | โมดูลพื้นฐานของ Admin Framework |
| `templates/` | แม่แบบหน้าเว็บ (HTML) ของฝั่งผู้สมัครและหลังบ้าน |
| `Now/` | ไลบรารี Now.js (ซอร์สใน `Now/js`, ไฟล์ที่คอมไพล์แล้วใน `Now/dist`) |
| `Kotchasan/`, `Gcms/` | เฟรมเวิร์กฝั่ง PHP และคลาสพื้นฐาน |
| `api.php` | จุดเข้า API (`api/enroll/...`) |
| `install/` | ตัวติดตั้งและตัวอัปเกรดฐานข้อมูล |
| `language/` | ไฟล์ภาษา (`th`, `en`) |
| `settings/`, `datas/` | ค่ากำหนดและไฟล์ที่ระบบสร้าง (ไม่ถูกเก็บใน Git) |

## การพัฒนา

### ทดสอบโมดูล enroll

ชุดทดสอบเป็นสคริปต์ PHP ไม่ต้องเปิดเบราว์เซอร์ แต่ละชุดจะสร้างฐานข้อมูลทดสอบของตัวเองจาก `modules/enroll/install/database.sql` แล้วลบทิ้งเมื่อเสร็จ

```bash
php modules/enroll/tests/run.php
```

ค่าเชื่อมต่อ MySQL สำหรับทดสอบ (ค่าเริ่มต้น `root` ไม่มีรหัสผ่าน) แก้ได้ที่ `modules/enroll/tests/harness.php`

### คอมไพล์ JavaScript ของ Now.js

ต้องทำเฉพาะเมื่อแก้ซอร์สใน `Now/js` (ต้องมี Node.js)

```bash
npm install
npm run build          # คอมไพล์ทุกชุด
npm run build:table    # คอมไพล์เฉพาะชุดเดียว เช่น table, graph, queue
npm test               # รัน vitest
```

## ความปลอดภัย

- เปลี่ยนรหัสผ่านผู้ดูแลหลังติดตั้ง และใช้ HTTPS กับระบบจริง
- ข้อมูลผู้สมัครมีข้อมูลส่วนบุคคล (เลขบัตรประชาชน เบอร์โทร ที่อยู่) ควรจำกัดสิทธิ์เจ้าหน้าที่ที่เข้าถึงได้ และจัดเก็บตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA)
- อย่านำ `settings/` และ `datas/` ขึ้นที่สาธารณะ (ถูกยกเว้นใน `.gitignore` แล้ว)
- พบช่องโหว่ โปรดแจ้งเจ้าของโปรเจ็คโดยตรงก่อนเปิดเผยสาธารณะ
